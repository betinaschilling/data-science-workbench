# Data Science Workbench

Laboratório pessoal para aprendizagem, estudos analíticos e desenvolvimento de projetos de ciência de dados.

## Organização

- `projects/`: estudos em incubação, ativos e concluídos.
- `learning/`: trilhas de aprendizagem por domínio.
- `engineering/`: SQL, qualidade, pipelines, Databricks, Spark e analytics engineering.
- `knowledge/`: conceitos, métodos, métricas, artigos e tradução para negócio.
- `templates/`: estruturas reutilizáveis para novos estudos.
- `packages/`: componentes Python compartilhados.
- `archive/`: versões históricas migradas de repositórios anteriores.
- `docs/`: metodologia, decisões, padrões e roadmap.
- `.codex/`: agentes personalizados para liderança, revisão e mentoria.

## Princípios

1. Formular a pergunta antes de escolher o método.
2. Auditar e documentar os dados antes de modelar.
3. Separar descrição, inferência, previsão, causalidade e decisão.
4. Validar temporalmente quando houver dependência no tempo.
5. Não transformar evidência fraca em recomendação forte.
6. Priorizar Python; usar SQL na preparação; usar R apenas quando não houver alternativa viável em Python.
7. Registrar decisões humanas críticas e manter resultados reproduzíveis.

Consulte [AGENTS.md](AGENTS.md) para a forma de trabalho dos agentes e [CONTRIBUTING.md](CONTRIBUTING.md) para criar novos estudos.
