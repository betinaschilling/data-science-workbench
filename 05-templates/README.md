# 05 — Templates

Estruturas reutilizáveis e ordenadas para estudos analíticos, machine learning, séries temporais, causalidade, experimentação, analytics engineering e comunicação corporativa.

## Categorias

- `01-analytical-study/`: estrutura base para estudos analíticos.
- `02-machine-learning/`: estrutura base para projetos de machine learning.
- `03-time-series/`: estrutura base para estudos e modelos de séries temporais.
- `04-causal-study/`: estrutura base para estudos causais.
- `05-experiment/`: estrutura base para experimentação.
- `06-analytics-engineering/`: estrutura base para analytics engineering.
- `07-corporate-presentations/`: identidade visual e layouts reutilizáveis para apresentações corporativas.
