# Apresentações corporativas

Modelos reutilizáveis para comunicação executiva de análises, ciência de dados e forecasting.

## C1D ForecastLab

O arquivo `C1D_ForecastLab_Manual_Layouts_Corporativos.pptx` reúne:

- manual da identidade visual C1D ForecastLab;
- paleta, tipografia e componentes gráficos;
- layouts corporativos para apresentações de forecasting;
- páginas para contexto, método, indicadores, resultados, riscos e recomendações;
- elementos editáveis no PowerPoint.

O modelo pode ser adaptado à identidade visual da organização parceira sem remover a assinatura visual do C1D ForecastLab.
